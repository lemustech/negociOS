# NegociOS Pro — Sistema Administrativo & POS

Sistema administrativo y punto de venta (POS) en tiempo real, desarrollado por **Lemustech Co.** Funciona como aplicación web instalable (PWA): se usa desde el navegador del teléfono, la tablet o la computadora, sin instalaciones complicadas.

## ✨ Características

- 🧾 **Punto de venta (POS)** con impresión de comprobantes
- 📦 **Gestión administrativa** de ventas e inventario en tiempo real
- 🔐 **Usuarios y autenticación** con Firebase Auth
- ☁️ **Datos sincronizados** en la nube con Cloud Firestore: lo que se registra en un dispositivo se ve al instante en los demás
- 📱 **Interfaz tipo app**, responsive y optimizada para pantallas táctiles
- 🎉 Experiencia cuidada al detalle: animaciones suaves y confirmaciones visuales

## 🛠️ Stack tecnológico

- HTML5 + JavaScript
- Tailwind CSS
- Firebase (Authentication + Cloud Firestore)
- Font Awesome · Plus Jakarta Sans · JetBrains Mono

## 🚀 Uso

Abre `index.html` en el navegador o despliega el proyecto en cualquier hosting estático. Requiere conexión a internet para sincronizar con Firebase.
